{# Methodology #}

How SLA Predictions Work

Vouch predicts SLA breaches by combining two signals:

  1. Age fraction — how close the PR already is to the {{ sla_hours }}-hour limit
  2. Reviewer load — if all assigned reviewers are currently overloaded, the review is statistically less likely to arrive before the deadline

Breach probability = (age_fraction × 0.60) + (reviewer_avg_load × 0.40)

Predictions surface {{ horizon_hours }} hours before the projected breach, giving engineering managers time to reassign or escalate. This is a model — not a guarantee. Use it to prioritise, not to blame.
