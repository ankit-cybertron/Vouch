Vouch Mathematical Invariant
residual_risk = change_risk × (1 − review_confidence)

High change risk alone does not mandate re-queuing if senior review depth is thorough. A pull request is re-queued only when residual risk exceeds calibrated safety thresholds (≥ 0.65).

The Three-Model Ensemble Architecture

Scored continuously as pull requests evolve, aggregating signals from Git diffs, conversation timelines, and reviewer session states.

01 XGBoost Classifier

Change Risk Model

Computes the intrinsic defect probability of the code change based on diff volume, file churn, deletion ratios, and historical author defect density.

  • Lines Changed: Additions vs deletions entropy
  • Sensitive Paths: Auth, crypto, payments, infra
  • File Dispersal: Cross-module entanglement index
02 DistilBERT NLP

Review Depth Model

Evaluates the qualitative thoroughness of reviewer comments, distinguishing substantive architecture critiques from trivial stylistic nits or instant approvals.

  • Substantive Dialogue: Semantic inquiry scoring
  • Code-Level Review: Inline hunk discussion density
  • Superficial Rejection: Flags fast "LGTM" rubber stamps
03 Bayesian Attention

Reviewer Attention Model

Models reviewer cognitive load, fatigue, session duration, and prior domain familiarity to determine if reviewers had adequate attention bandwidth.

  • Session Duration: Time elapsed vs diff magnitude
  • Concurrent Load: Simultaneous open reviews
  • Module Familiarity: Historic commit authorship in path
