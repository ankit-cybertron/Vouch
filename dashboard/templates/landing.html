Workflow Pipeline

How Vouch works

Infrastructure for code review visibility in three automated steps.

STEP 01

Connect GitHub

Install the Vouch GitHub App or connect via OAuth. Vouch automatically listens to pull request webhooks across your repositories.

GET /api/github/webhooks → 200 OK
STEP 02

Analyze the pull request

Vouch evaluates change complexity, path sensitivity, reviewer active session timing, and inline comment technical depth.

Scoring diff + scrutiny + attention
STEP 03

Understand residual risk

Engineering leads get real-time visibility into residual risk. High-risk PRs with shallow reviews are flagged for re-review before production rollout.

Residual Risk: 0.81 → Re-queue PR
Product Capabilities

Engineered for technical rigor

Actionable visibility into review thoroughness and code safety.

PR Intelligence

Evaluates diff magnitude, file churn, path criticality (`/auth/`, `/billing/`, SQL migrations), and author velocity.

Residual Risk

Quantifies unmitigated risk using the formula Residual Risk = Change Risk × (1 − Review Scrutiny).

Review Depth

Parses review comment threads to distinguish deep technical critiques from low-scrutiny approval comments.

Reviewer Attention

Measures reviewer active session duration and attention ratio relative to lines of code changed.

Rubber-Stamp Detection

Instantly flags 45-second approvals on complex, high-impact pull requests before deployment.

Explainable Risk Signals

Provides clear, audit-ready summaries detailing exact risk drivers for engineering management.
