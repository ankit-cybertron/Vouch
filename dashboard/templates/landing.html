▶ Step-by-step: Create a GitHub App (recommended)
  1. Go to github.com/settings/apps/new
  2. Set GitHub App name: Vouch
  3. Set Homepage URL: {{ computed_app_callback_uri.split('/auth')[0] }}
  4. Under Post installation → Setup URL, paste:
    {{ computed_app_callback_uri }}
  5. Enable "Redirect on update"
  6. Set Permissions → Repository: Contents (Read), Pull requests (Read), Metadata (Read)
  7. Click Create GitHub App
  8. Copy the App ID and generate a Private Key (.pem)
  9. Add to .env: 
    GITHUB_APP_ID=your_app_id
GITHUB_APP_PRIVATE_KEY_PATH=/path/to/vouch.pem
GITHUB_APP_INSTALL_URL=https://github.com/apps/vouch/installations/new
APP_BASE_URL={{ computed_app_callback_uri.split('/auth')[0] }}
  10. Restart the server — the Install Vouch on GitHub button will appear
▶ Step-by-step: Create a GitHub OAuth App (simpler, user tokens)
  1. Go to github.com/settings/applications/new
  2. Set Application name: Vouch
  3. Set Homepage URL: {{ computed_oauth_callback_uri.split('/auth')[0] }}
  4. Set Authorization callback URL (paste exactly): {{ computed_oauth_callback_uri }}
  5. Click Register application
  6. Copy Client ID and generate a new Client Secret
  7. Add to .env: 
    GITHUB_CLIENT_ID=your_client_id
GITHUB_CLIENT_SECRET=your_client_secret
APP_BASE_URL={{ computed_oauth_callback_uri.split('/auth')[0] }}
  8. Restart the server — the Connect with GitHub button will work
